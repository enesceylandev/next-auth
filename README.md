# next-auth

A Next.js authentication starter using Auth0 and NextAuth.js.

## Branch Structure

- `dev/v1.0.0`: Main development branch for v1.0.0
- `prod/v1.0.0`: Production-ready code

## Workflow

- All development happens on `dev/v1.0.0`.
- Regularly push your commits to keep the branch up to date.
- Open pull requests for merging features or bug fixes into `dev/v1.0.0`.
- When ready for release, open a PR from `dev/v1.0.0` to `prod/v1.0.0`.
